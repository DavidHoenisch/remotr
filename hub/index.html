Share with the community

Remotr Hub grows through pull requests. Add your manifest, cron definition, or full configuration repo to the catalog so others can discover it.

  1. Fork the Remotr repository on GitHub.
  2. Add a YAML snippet under hub/snippets/ (optional but recommended).
  3. Register your entry in hub/data/catalog.json with title, description, tags, and distros. Third-party sourceUrl links must include a pinned sourceCommit hash.
  4. Open a pull request. We'll review and merge it into the hub.
Edit catalog.json

What belongs here?

  • Configuration slices for modules/ (desired state)
  • crons.yaml jobs, cron modules, and builtin references
  • Security baselines, package bundles, systemd units
  • Links to community configuration repositories

Prefer small, focused entries over monolithic configs. Import snippets into your repo with remotr hub snippet import <entry-id>, then list the module from a fleet manifest.yaml.
