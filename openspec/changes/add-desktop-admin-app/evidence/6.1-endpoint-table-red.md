- Verification IDs: `OS-DFV-006`, `OS-DFV-007`, `OS-DFV-008`
- Public seam: rendered Endpoint inventory component and row action
- Test layers: Testing Library semantic table roles/names, independently known
  canonical statuses, independent freshness, deterministic Label columns,
  pointer row action, and authenticated empty state
- Command: `pnpm exec vitest run src/endpoints/EndpointTable.test.tsx`
- Result: intended red (`exit 1`)

Vitest cannot resolve `./EndpointTable` because the production inventory
component does not exist. The seven-row fixture independently fixes compliant,
drifted, unsupported, check-failed, deferred, apply-failed, and not-reported
labels. A compliant Endpoint is stale and a not-reported Endpoint is recent, so
the table must render compliance and freshness as separate evidence and may not
invent healthy, online, or offline states.

The contract also fixes reported and desired agent versions, Release ref,
stable UTC evidence time, and configured `environment` then `region` Label
columns even when row Labels arrive in another order. An unselected `owner`
Label must not leak into the default table, while the exact Endpoint identity
is passed to the inspect action for later full-Label detail.

The zero-row case is an authenticated empty result, not a connection error. It
must explain that no Endpoints are enrolled and expose the permitted enrollment
token recovery workflow. Task 6.2 supplies the semantic dense table and empty
state needed to make this contract green.
