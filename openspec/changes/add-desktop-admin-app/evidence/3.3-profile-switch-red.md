- Verification IDs: `OS-DOA-006`, `OS-DOA-007`
- Public seam: desktop session manager
- Test layers: focused native Go concurrency test with a channel-controlled
  external connection boundary and independently known Operator identities
- Command: `go test ./... -run '^TestSessionManager' -count=1`
- Result: intended red (`exit 1`)

The compiler reported that the expected session boundary and safe state models
were absent, including `ConnectedSession`, `OperatorIdentity`,
`WorkspaceSnapshot`, `SessionState`, and `SessionStatus`.

The committed tests contain no sleeps or database side channels. They specify
that a switch clears identity, workspace rows, selection, overlay, and transient
action output while the new connection is still pending; a subsequent switch
cancels the obsolete request and admits only the new server's known identity;
and a failed switch retains none of the previous server's operational state.
Task 3.4 implements only enough session coordination to make these assertions
green.
