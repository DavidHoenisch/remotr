- Verification ID: `OS-DOA-018`.
- Public seam: the advertised Linux package target and the native DEB consumed
  by the host package manager and launcher.
- Selected layers: focused real-DEB build/install/launch/remove lifecycle,
  exact control and payload assertions, unsupported-architecture and
  package-version negatives, smoke-before-upload CI ordering, real installed
  Wails launch, nested desktop regressions, and the root suite.

## Intended red

Command:

`env GOCACHE=/tmp/remotr-gocache GOTMPDIR=/tmp/remotr-gotmp mise exec -- go test ./internal/desktoplayout -run '^TestAdvertisedLinuxPackageHasNativeInstallLifecycleEvidence$' -count=1`

The focused test failed because no package-target advertisement, DEB builder,
isolated install/remove smoke, Make lifecycle target, or evidenced CI upload
existed. This is the intended red before Linux/amd64 DEB is advertised even as
an unsigned development snapshot.

## Green verification

- The focused lifecycle test built a real DEB, asserted exact package/version/
  architecture fields and payload paths, exercised containerized package
  install/remove plus extracted-payload launch, and rejected arm64 and a
  mismatched expected version.
- `make desktop-package-smoke DESKTOP_VERSION=0.0.0-deb-smoke.local` built the
  production Wails Linux/amd64 binary with its exact embedded version and
  produced a root-owned DEB payload.
- The exact 6,955,066-byte package had SHA-256
  `6f8a63319d3c105d41d478ff9da7d9d002c48516ce9ec050fc5fbaaacd9b7dae`.
- Native `dpkg` inside
  `debian:13-slim@sha256:020c0d20b9880058cbe785a9db107156c3c75c2ac944a6aa7ab59f2add76a7bd`
  installed the exact linux/amd64 package, observed its executable, desktop
  entry, AppStream metadata, and hicolor icon, then purged the package and
  proved those paths and its package-database record were absent.
- The deliberately minimal package-manager fixture warned that GTK/WebKit
  dependencies were not installed; the subsequent host-native Xvfb launch of
  the exact extracted package payload passed with title `Remotr Desktop` and
  embedded version `0.0.0-deb-smoke.local`.
- The only advertised target is Linux/amd64 DEB, classified as an unsigned,
  seven-day CI development artifact with `releaseEligible: false`. Signed
  release output is explicitly `not-configured`, and CI uploads only after the
  complete package smoke succeeds.
- Desktop-file/AppStream validation, the complete root desktop-layout package,
  the complete nested desktop Go suite, and strict OpenSpec validation passed.
- `mise exec -- make test` passed all 37 discovered fuzz seed corpora and the
