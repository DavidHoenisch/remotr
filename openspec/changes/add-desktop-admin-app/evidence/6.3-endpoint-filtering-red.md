The current table has no `Search Endpoints` searchbox, explicit Fleet,
compliance, or freshness filters, sortable Fleet header, clear-all control, or
search-focus shortcut. The failures therefore occur at operator-visible
controls rather than private filtering helpers.

The controlled four-Endpoint fixture fixes case-insensitive matches for
Endpoint identity, Fleet, username, Label key, and Label value. Its intersection
case leaves only `endpoint-alpha` after search plus Fleet, compliance, and
freshness filters; clear-all must restore every control and all four rows in one
action.

Input order deliberately differs from the expected Fleet sort. Equal Fleet
values must resolve by Endpoint identity, yielding alpha/beta then
charlie/delta. Slash and Ctrl+K must focus the current-page search without
entering the shortcut character, while slash typed after the search owns focus
must remain ordinary query input. Task 6.4 implements the shared state and
interaction behavior needed to make the slice green.
