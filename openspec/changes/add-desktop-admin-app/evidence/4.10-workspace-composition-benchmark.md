# Task 4.10 workspace composition benchmark

- Public seam: production workspace composition after authenticated Admin API
  reads complete
- Benchmark: `BenchmarkWorkspaceComposition`
- Command: `GOMAXPROCS=1 go test -run '^$' -bench '^BenchmarkWorkspaceComposition$' -benchmem -benchtime=200ms -count=3`
- Runtime: Go 1.26.5, Linux 7.0.0-27-generic, amd64
- CPU: AMD Ryzen AI 9 HX 370 with Radeon 890M
- Result: pass (`exit 0`)

The benchmark uses deterministic representative typed fixtures containing
Endpoint identity, versions, users, three Labels, check-in freshness, one State
item per Endpoint, Fleet distributions, Change summaries, and up to 50 Activity
events. Setup is outside the timed loop, and the benchmark calls the same
composition function used after live workspace reads.
