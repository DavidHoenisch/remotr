The App records the exact originating control, requests detail lazily, and
mounts the focused shell overlay only for an identity-matched response. A
monotonic selection generation ignores late responses, while the existing Go
Endpoint-detail service cancels its obsolete request generation. A mismatch or
classified load failure renders only safe recovery guidance instead of foreign
Endpoint evidence.

The overlay shows the exact Endpoint identity, Fleet, compliance, freshness,
reported agent version, Release ref, and Labels before any evidence tabs and
contains no mutation control. Overview, State, Schedules, Firewall, and System
are semantic tabs. Each tab consumes its own section result; ready structured
fields remain usable while connection and authorization failures render local
shared data-state primitives with classified guidance. State items,
subresults, schedules, firewall entries, and system facts are rendered as
bounded text fields without executable markup.

Closing through either the visible control or Escape increments the selection
generation, removes only the overlay, and focuses the originating Inspect
control. Because the inventory remains mounted underneath, the exact search,
selectors, sort direction, result count, and horizontal scroll offset are
retained.

At a controlled 1100-by-720 browser viewport, the document remained exactly at
the viewport extents. The overlay occupied a 720-by-672 pane with a 719-pixel
content region and no horizontal or vertical overflow on Overview; all five
tabs fit in the 677-pixel tab strip. Selecting Schedules showed only
`Schedule evidence unavailable` with its exact recovery guidance, the dialog
remained open, and the visible close action restored focus to
`Inspect endpoint-alpha`. The browser emitted no errors.
