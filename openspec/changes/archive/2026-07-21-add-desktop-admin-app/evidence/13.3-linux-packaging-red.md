# 13.3 Linux packaging identity — red evidence

- Verification ID: `OS-DOA-018`.
- Public seam: the Wails native Linux application options and committed Linux
  packaging assets consumed by launchers and software catalogs.
- Selected layers: focused native-option and packaging-contract test, PNG
  dimension/transparency checks, desktop-entry semantics, AppStream XML
  identity, a negative non-Linux asset scan, native Linux build, desktop Go
  regression tests, and the root regression suite.

## Intended red

Command:

`env GOCACHE=/tmp/remotr-gocache GOTMPDIR=/tmp/remotr-gotmp mise exec -- go test ./... -run '^TestLinuxApplicationPackagingIdentifiesRemotrDesktop$' -count=1`

The focused test failed because the `remotr-v1` icon manifest and source, Wails
`appicon.png`, hicolor launcher icon, `remotr-desktop.desktop`, and AppStream
metadata were absent. The existing Wails Linux program name remained
`remotr-desktop`, isolating the intended red to the missing application icon and
Linux packaging identity.

## Green verification

- The focused test passed with schema-versioned `remotr-v1` source and Wails
  icons at 1024×1024, a derived 256×256 hicolor launcher icon, transparent
  corners, and the same icon bytes in the native Linux Wails options.
- The original Remotr mark depicts four Endpoint nodes pulling toward a central
  terminal, uses no words or operating-system marks, and was created for this
  project rather than copied from the supplied interface references.
- Chroma removal left 504,899 fully transparent pixels and 2,182 antialiased
  pixels in the canonical icon; all four corners were transparent and the edge
  scan found no magenta-like partial-alpha pixels.
- `desktop-file-validate build/linux/remotr-desktop.desktop` passed.
- `appstreamcli validate --no-net build/linux/io.github.davidhoenisch.remotr.desktop.metainfo.xml`
  passed.
- The complete nested desktop Go suite passed.
- `mise exec -- make desktop-build` produced a stripped Linux/amd64 ELF with
  the `webkit2_41` tag and the new embedded icon.
- The root desktop-layout suite and strict OpenSpec validation passed.
- `mise exec -- make test` passed all 37 discovered fuzz seed corpora and the
  complete root Go suite.
- A negative path scan found no Darwin, macOS, Windows, ICNS, ICO, DMG, PKG,
  EXE, or MSI packaging asset beneath `desktop/build`.
