`env GOCACHE=/tmp/remotr-gocache GOTMPDIR=/tmp/remotr-gotmp mise exec -- go test ./internal/desktoplayout -run '^TestDesktopGuidesCoverLinuxSetupCredentialsGitParityAndRecovery$' -count=1`

reference, and their published navigation entries did not exist. The failure

  release-layout, and repository contract package.
- `openspec validate add-desktop-admin-app --strict` passes.

development artifact, reference-only credential reuse, one-time bootstrap token
handling, Git-bound desired-state workflows, troubleshooting, and supported CLI
fallback/recovery. It does not claim macOS, Windows, signed release output, or
full desktop parity.
