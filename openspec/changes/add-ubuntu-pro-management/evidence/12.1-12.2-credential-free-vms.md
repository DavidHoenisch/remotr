# Tasks 12.1 and 12.2 credential-free VM evidence

- Verification IDs: OS-UPM-003 through OS-UPM-005, OS-UPM-008 through
  OS-UPM-011, OS-UPM-014, OS-UPM-024 through OS-UPM-027, OS-LPC-011, and
  OS-LPC-012.
- Public seam: the Ubuntu Pro provider through `executor.Apply` and
  `executor.Check`, compiled with the `vmsafety` tag and executed as root in a
  pinned amd64/libvirt Ubuntu guest.
- Credential boundary: the harness rejects `REMOTR_UBUNTU_PRO_TOKEN` and
  `UBUNTU_PRO_TOKEN`; it creates a mode-0600 synthetic canary, supplies it only
  through the provider resolver and protected stdin, and uses an independently
  specified stateful `/usr/bin/pro api` double. No Canonical endpoint, live
  subscription, contract, or entitled native effect is exercised.
- Intended infrastructure red: the CI contract test reported every manifest
  selector missing and the harness missing the real-token guard, release
  routing, negative identity, secret-canary, and public VM-test seams.
- Green infrastructure command:
  `go test ./internal/cicontract -run '^TestUbuntuProVMSelectorsUseCredentialFreeHarness$' -count=1`.
- Negative VM command:
  `make provider-matrix-vm-ubuntu-pro-negative-identities` on pinned
  `cloud-image/ubuntu-24.04@20260705.0.0`. Pop!_OS, Linux Mint, conflicting
  os-release sources, Ubuntu 25.10, and Ubuntu 28.04 all failed before API,
  protected-input, or resolver calls.
- Secret VM command:
  `make provider-matrix-vm-ubuntu-pro-secret-canary` on the same pinned guest.
  Attach, public Check, second-Apply idempotence, and detach passed; the output
  contained no canary.
- Harness safety: guest output is capped at 16 KiB, canary-scanned, and retained
  as a bounded redacted `ubuntu-pro.failure.*.log` only on failure. The guest
  token and test binary are checked absent before teardown. The common destroy
  path verifies that no domain, overlay disk, private key, or test network is
  retained.

The fixture establishes credential-free provider behavior on a real Ubuntu
host. It deliberately makes no claim about successful communication with
Canonical or any entitled package, repository, kernel, snap, Livepatch, ROS,
Anbox Cloud, FIPS, or compliance-tool effect.
